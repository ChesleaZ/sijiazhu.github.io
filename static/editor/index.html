如何更新正式主页？

保存草稿仅写入本浏览器，不会更改公开网站。

  1. 点击「导出网站配置」，下载 homepage-config.json。
  2. 打开 GitHub 配置上传目录，上传刚下载的同名文件。
  3. 点击 Commit changes。自动部署完成后，正式主页即使用新配置。

也可以把导出的文件发给 Codex，帮助你发布。此编辑页不保存 GitHub 密码或令牌。
