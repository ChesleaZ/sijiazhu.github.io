保存与发布说明

草稿包含所有页面。保存保留在本浏览器；「发布全站修改」会一次提交全部页面与外观设置。

  1. 首次点击「连接 GitHub」，仅授权此网站仓库的 Contents 读写权限。
  2. 在下拉菜单切换页面，修改左侧控件，或直接点击右侧文字编辑。
  3. 点击「发布全站修改」，等待「官网已更新」。

精选论文和完整列表使用同一份论文数据。「全站外观」同时影响所有页面。令牌仅保留在当前页面内存中，刷新后需重新连接。

连接 GitHub 发布

仅授权 ChesleaZ/sijiazhu.github.io，直接提交全站配置。

  1. 在 GitHub 创建 fine-grained token ↗
  2. Repository access 选择 Only select repositories，仅勾选 sijiazhu.github.io。
  3. Repository permissions → Contents: Read and write，设置有效期，由你点击 Generate token。

令牌只发送到 GitHub API，不保存到草稿或网站文件。请直接粘贴在这里，不要发送到聊天中。
