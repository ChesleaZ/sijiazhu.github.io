如何直接发布？

保存草稿保留在本浏览器；发布到官网会提交当前配置并自动部署。

  1. 首次点击「连接 GitHub」，使用仅授权此网站仓库的 fine-grained token。
  2. 调整预览，点击「发布到官网」。
  3. 等页面提示「官网已更新」，即可查看正式主页。

令牌仅在当前页面内存中使用，刷新后需重新连接。导出配置仍可用作备份。

连接 GitHub 发布

只授权 ChesleaZ/sijiazhu.github.io，由编辑器直接提交主页配置。

  1. 在 GitHub 创建 fine-grained token ↗
  2. Repository access 选择 Only select repositories，仅勾选 sijiazhu.github.io。
  3. Repository permissions → Contents: Read and write，设置有效期后由你点击 Generate token。

令牌只发送到 GitHub API，不保存到草稿或网站文件。请直接粘贴在这里，不要发送到聊天中。
